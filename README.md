# 🎯 Guess My Number

A simple number guessing game built using HTML, CSS, and JavaScript.

## 🎮 How to Play

- Guess a secret number between 1 and 20.
- Enter your guess and click **Check!**
- The game tells you whether your guess is too high or too low.
- Start with a score of 20.
- Try to get the highest possible score!

## ✨ Features

- Random secret number generation
- Score system
- Highscore tracking
- Win and lose states
- Restart game functionality
- Interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
